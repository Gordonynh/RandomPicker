# 随机抽选

桌面上的一个小圆钮，按一下抽一个人。

## 怎么用

- **左键点一下** —— 抽一个人
- **左键按住拖** —— 挪动悬浮窗（拖不出屏幕，但可以压在任务栏上）
- **右键** —— 设置菜单

抽中之后：屏幕中央弹出大字，同时 ClassIsland 主界面发一条提醒。两个都能在菜单里单独关掉。

## 名单

纯文本，一行一个名字，**没有引号、没有 JSON**，记事本就能改：

```
张三
李四
王五
```

- 空行和以 `#` 开头的行会被忽略
- 重复的名字只算一个
- **保存后立刻生效**，不用重启

文件位置：右键菜单 → **打开名单文件**。首次运行会自动生成一份带说明的示例。

## 三种模式

| 模式         | 行为                         |
| ---------- | -------------------------- |
| **随机抽选**   | 每次都从全部名单里抽，只回避「和上一次是同一个人」  |
| **本轮内不重复** | 抽到的人本轮不再出现；抽完一轮自动开新一轮      |
| **拍照抽人**   | 用摄像头拍一张，从检测到的人脸里随机挑一个，裁出人像 |

菜单顶部会显示当前模式和本轮剩余人数。想提前重来，点「开始新一轮」。

随机数直接取自操作系统的熵源（`RandomNumberGenerator`），  
不存在「拿时间戳当种子、同一毫秒内连抽拿到同一个人」这种问题。

## 拍照抽人

**应用设置 → 随机抽选** 里有完整设置和「试拍一次」。

> ⚠ **只能检测正对镜头的人脸。** 没有可离线使用的模型能认出后脑勺，背对镜头的人抽不到。  
> 用「试拍一次」对着真实场景量一遍再决定用不用——它会打出分辨率、检出人数、各步耗时，  
> 并把画了检测框的照片显示出来。

用的是 OpenCV Zoo 的 **YuNet**（232 KB ONNX），靠 ONNX Runtime 跑，两样都随插件打包，  
全程离线。所以这个插件包是 4.6 MB，其余几个都只有几十 KB。

在一张几十人的合影上实测，单次推理检出 97 张脸、耗时 63 ms；  
作为对照，Windows 自带的人脸检测整帧只检出 4 张，分块放大到 58 张要 736 ms。

几个可调项：

- **摄像头保持时间**（默认 120 秒）：打开摄像头要 0.2~1.5 秒，首帧还得再等一会儿；  
  开着的时候每帧只要几十毫秒。所以抽完先不关，连着抽几乎是瞬时的。  
  代价是这期间摄像头指示灯亮着，到点自动关掉。设成 0 就是用完立刻关，页面上也有「立刻关闭」。
- **人脸分数阈值**（默认 0.50）：0.50 检出 97 人，0.70 只剩 60 人，  
  而 **OpenCV 默认的 0.90 只有 1 人**——那个默认值在人多的场景下完全不能用。
- **分块检测**（默认关）：把画面切块各检一遍再合并，能从 97 提到 132，代价是每块一次推理。
- **保存原图**（默认关）：合影是在场者的影像，不开的时候整帧只在内存里待到裁完就丢。

### 回避最近抽过的人

独立随机的意思是上一次抽了谁对这一次毫无影响——30 个人里连着两次撞上的概率是 1/30，  
抽十几次几乎一定会遇到，看着就很像「坏了」。

所以拍照模式会**回避最近抽过的几个人**（默认 6 个）。人不会乱动，  
所以用人脸在画面里的位置当身份：位置落在最近抽过的那几个附近的，这一轮先不抽。  
避开之后一个都不剩时退回全体重挑——宁可重复也不能抽不出人。设成「不回避」就是纯独立随机。

回避记录只在内存里：摄像头一挪、人一换座位，那些坐标就没意义了，  
存进配置反而会把过时的回避带到下一次开机。

### 混入文字抽选

拍照模式下可以设一个概率，按这个概率改成按名单抽名字。一直是照片会腻，  
偶尔蹦一个名字更有意思，也照顾到没被拍进画面的人。

**文字抽选可以用单独一份名单**（`名单-文字.txt`），和拍照那套完全隔离：  
想让文字抽选只覆盖某几个人时不必动主名单。  
两份名单共用同一套「本轮已抽」状态——名单隔离是为了圈定范围，不是各记各的进度。

## 其他设置

- **悬浮窗大小**：小 / 中 / 大
- **抽中之后**：中央大字开关、ClassIsland 提醒开关、大字停留时长（1.5 / 2.5 / 4 秒）
- **隐藏悬浮窗**：藏起来；想叫回来重启 ClassIsland

位置、模式、各项开关都会自动记住。

## 置顶

悬浮窗和中央大字都会被持续按在最顶层：除了设 `Topmost`，还会加上  
`WS_EX_TOOLWINDOW`（不进 Alt+Tab）和 `WS_EX_NOACTIVATE`（不抢焦点），  
并由定时器反复调用 `SetWindowPos(HWND_TOPMOST)` 顶回去。  
全是文档化的公开 API，不改系统设置，也不碰别的进程。

## 开源信息

- 仓库：<https://github.com/Gordonynh/RandomPicker>　·　MIT 协议
- 针对 ClassIsland 2.1（Avalonia）构建；随 release 提供打包好的 `.cipx`
- 从源码编译：克隆到 ClassIsland 源码树的 `plugins/` 目录下，`dotnet build -c Release`

# 二次开发版本说明（4.0.0.0 · yty16）

以上为原作者 GordonYoung 的原始 README，内容未做任何改动。以下单独记录本分支  
（fork 自 [Gordonynh/RandomPicker](https://github.com/Gordonynh/RandomPicker)）新增与改进的功能。  
新增功能

- **多份名单**：共 5 份（`名单.txt` ~ `名单5.txt`），悬浮窗右键菜单或设置页切换，权重跨名单共用。
- **小组抽选**：按名单顺序切组、每组人数可调，抽中后大字分行显示组名和组员，小组有独立轮次。
- **名单权重**：每个名字可单独加权，设置页已升级为**可视化滑条**的编辑器，逐人拖动调节更直观。
- **一次抽多人**：URL / HTTP / 自动化行动可带 `count`，一次抽互不重复的多人。
- **拍照抽人增强**：人脸位置回避最近抽过的人（解决连抽同一个）、混入文字抽选、分块检测、独立文字名单。

## 悬浮窗控制

- **隐藏后可恢复**：悬浮窗右键「隐藏悬浮窗」后，设置页开关、快捷键、URL、自动化行动都能叫回来，无需重启。
- **全局快捷键**：默认 `Ctrl + Alt + R`，任意界面一键切换悬浮窗显隐（可在设置页改组合键，占用时自动失效）。
- **悬浮窗缩放系数**：0.5× ~ 2.0× 自由缩放，适配不同屏幕（设置页滑条）。
- **悬浮窗显隐 URL / HTTP**：`classisland://plugins/randompicker/show|hide|toggle`，HTTP 接口同名路由 `/randompicker/show|hide|toggle`。

## 课堂控制

- **下课禁用**：开启后课间内所有点名入口不响应，圆钮会闪现「课间禁用」提示。
- **打断点名**：开启时新抽选立刻关掉上一条还没播完的中央大字并开始新的点名；  
  关闭时上一次点名播完前新的请求会被忽略。

## 自动化

- **触发器**：抽中人选 / 名单抽人 / 拍照抽人 / 一次抽多人 / 抽中指定名字 / 当悬浮窗隐藏时 / 当悬浮窗显示时。
- **行动**：抽选一次 / 名单抽人 / 拍照抽人 / 一次抽多人 / 抽一个小组 / 隐藏悬浮窗 / 显示悬浮窗。
- **规则**：最近抽中的人是 / 最近一次抽选方式是 / 本轮剩余人数不超过。

## 接口

「接口」是给**别的程序**指挥抽选用的：把下面的链接发给快捷方式、浏览器地址栏、  
命令行（`start "" "链接"`）、课堂管理工具或自动化软件，打开链接就等于按了一下悬浮窗。  
两类入口功能一致，按场景任选。

### classisland:// 链接（推荐）

不用开任何开关，装好插件就能用：

| 链接                                                  | 作用                |
| --------------------------------------------------- | ----------------- |
| `classisland://plugins/randompicker/pick`           | 按当前模式抽一人          |
| `classisland://plugins/randompicker/roster`         | 按名单抽一人            |
| `classisland://plugins/randompicker/roster?count=3` | 名单一次抽 3 人         |
| `classisland://plugins/randompicker/group`          | 抽一个小组             |
| `classisland://plugins/randompicker/photo`          | 拍照抽一人             |
| `classisland://plugins/randompicker/photo?count=2`  | 拍照一次抽 2 人         |
| `classisland://plugins/randompicker/multi`          | 一次抽多人（人数用设置页的默认值） |
| `classisland://plugins/randompicker/show`           | 显示悬浮窗             |
| `classisland://plugins/randompicker/hide`           | 隐藏悬浮窗             |
| `classisland://plugins/randompicker/toggle`         | 切换悬浮窗显隐           |

抽人类链接还可以追加查询参数（`?参数=值&参数=值`）：

| 参数       | 取值                                        | 说明                  |
| -------- | ----------------------------------------- | ------------------- |
| `kind`   | `auto` / `roster` / `photo` / `group`     | 指定抽选方式，压过当前模式       |
| `mode`   | `random` / `norepeat` / `photo` / `group` | 临时指定模式，抽完还原         |
| `count`  | 整数                                        | 一次抽多少人              |
| `roster` | `default` / `main` / `text`               | `text` 用「名单-文字.txt」 |
| `reveal` | `0` / `1`                                 | 是否弹中央大字             |
| `notify` | `0` / `1`                                 | 是否发 ClassIsland 提醒  |

完整示例：`classisland://plugins/randompicker/roster?count=2&mode=norepeat&notify=0`

### 本地 HTTP（默认关闭、只监听 127.0.0.1）

先在设置页打开「本地 HTTP 接口」，端口默认 17890；设了令牌就在链接后加 `&token=你的令牌`。  
查询参数与 classisland:// 完全相同：

```text
http://127.0.0.1:17890/randompicker/pick
http://127.0.0.1:17890/randompicker/roster?count=3
http://127.0.0.1:17890/randompicker/group
http://127.0.0.1:17890/randompicker/photo?count=2
http://127.0.0.1:17890/randompicker/multi
http://127.0.0.1:17890/randompicker/show
http://127.0.0.1:17890/randompicker/hide
http://127.0.0.1:17890/randompicker/toggle
http://127.0.0.1:17890/randompicker/status
```

最后一条 `/status` 不触发抽选，返回 JSON 状态（是否在监听、当前模式、名单人数、最近抽中的人）。
