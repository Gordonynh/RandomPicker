# 随机抽选

ClassIsland 的随机抽选插件。桌面上一个小球，点一下就从名单里抽人、抽小组，或者拍一张合影抽人脸。

## 安装

- 需要 **ClassIsland 2.1** 及以上
- 下载 `.cipx` 插件包，直接拖进 ClassIsland 窗口；或者放进应用数据目录的 `Cache/PluginPackages/` 再启动
- 装完在 **应用设置 → 随机抽选** 里能改所有参数

## 怎么用

- **左键点一下** —— 抽一次
- **左键按住拖** —— 挪动悬浮球（拖不出屏幕，但可以压在任务栏上）
- **右键** —— 弹出菜单（触摸屏按住不动也能弹）

抽中之后：屏幕中央亮出结果，同时 ClassIsland 主界面发一条提醒。这两个都能单独关掉。

位置、抽什么、各项开关都会自动记住。不小心把球藏了，看[藏起来之后怎么找回来](#藏起来之后怎么找回来)。

## 名单

一共 **5 份**名单，放在插件配置目录的 `namelib/` 下（`list1.txt` ~ `list5.txt`）。
用右键菜单 → **选择名单文件**，或者 **应用设置 → 随机抽选 → 选择名单** 切换。

每份都是纯文本，一行一个名字，**没有引号、没有 JSON**，记事本就能改：

```
@高一5班
张三
李四
王五
```

- 空行和以 `#` 开头的行会被忽略
- 重复的名字只算一个
- **保存后立刻生效**，不用重启
- 名单空着的话，插件会自己写一份十个人的示例进去

**给名单起名字**：第一行写 `@高一5班`，菜单和设置页就直接显示「高一5班」。
没起名字的那几份，显示为「名单1」「名单2」……
菜单里名字最多显示 5 个字，长了截断；设置页里显示完整的。

> 从旧版本升级：原来的「名单.txt」会在第一次启动时自动搬进 `namelib/list1.txt`，
> 老文件改名为「名单.txt.bak」留底，内容一点不丢。

## 抽什么

| 来源 | 抽出来的是 |
|---|---|
| **随机抽人** | 名单里的名字 |
| **随机抽组** | 小组，比如「C 组」。小组按设置直接算出来，不用写文件 |
| **拍照抽人** | 摄像头拍一张，从画面里的人脸里挑，裁出人像 |

三种来源都可以一次抽 1~3 个，一批之内不会重复。

## 右键菜单

```
抽一个
──────────
拍照抽人 / 随机抽人 / 随机抽组
抽取数量   ›  1 个 / 2 个 / 3 个
抽取模式   ›  不放回 / 放回
分组方式   ›  字母 / 数字
重置本轮
──────────
悬浮球大小 ›  小 / 中 / 大
结果显示方式 › 屏幕中央弹出 / ClassIsland 提醒 / 停留时长 ›
──────────
刷新插件状态
选择名单文件 › 高一5班 / 名单2 / 名单3 / 名单4 / 名单5
打开名单文件
打开插件设置
```

- **拍照抽人 / 随机抽人 / 随机抽组**：抽什么。切回「随机抽人」会恢复上次选的抽取模式。
- **抽取数量**：一次抽几个。抽不出那么多就少给几个。
- **抽取模式**：**不放回** = 抽过的不再出现，抽完一轮自动开始新一轮；
  **放回** = 每次都能再抽到，但刚抽过的会明显更难被抽中。名单和小组共用这个设定。
- **分组方式**：组名写成「A 组」还是「1 组」，只管抽组。
- **重置本轮**：名字不变，做的事看模式——**不放回**就是清空本轮记录、提前开新一轮；
  **放回**没有轮次，重置的是「谁刚被抽过」这份降权记录，所有人回到同一权重。
- **选择名单文件**：在 5 份名单之间切换。有名字的显示名字，没名字的显示「名单2」这样。
  换名单会清空本轮记录——新名单里根本没有那些人。
- **刷新插件状态**：从磁盘把设置、名单、摄像头全部重读一遍，再把界面刷一遍。
  手动改过 `settings.json`、名单在别的程序里改过、摄像头被占住、或者想重来一次的时候用。
- **打开插件设置**：跳到 **应用设置 → 随机抽选**。

菜单里的设定在设置页里也都有，改哪边都一样，存的是同一份。菜单适合上课时随手点，
设置页适合一次配好。

## 抽组

小组不是名单，**不需要写文件**——按组数和组名写法直接算出来：

- **分组方式**：字母 = `A 组`、`B 组`……；数字 = `1 组`、`2 组`……
- **小组总数**：1 ~ 26（上限 26 是因为字母写法只到 Z）

两者都在 **应用设置 → 随机抽选** 里改，右键菜单里有「分组方式」的快捷切换。
改组数或换写法会清空本轮抽组记录——「A 组」和「1 组」本来就不是同一个组。

## 拍照抽人

**应用设置 → 随机抽选** 里有完整设置和「试拍一次」。

> ⚠ **只能检测正对镜头的人脸。** 背对镜头、低头、被挡住的人都抽不到。
> 用「试拍一次」对着真实场景量一遍再决定用不用——它会打出分辨率、检出人数、各步耗时，
> 并把画了检测框的照片显示出来，谁被漏掉一眼就能看见。

可调项（都在设置页）：

- **摄像头**：多个摄像头时选一个。
- **摄像头保持开启**：默认 120 秒。打开摄像头要一两秒，开着的时候再抽几乎是瞬时的；
  代价是这期间指示灯亮着，到点自动关。设成 0 就是用完立刻关，页面上也有「立刻关闭」。
- **检测阈值**：默认 0.50。**人多的场景别往上调**——调到 0.9 基本上就什么都检不出来了。
- **分块检测**：默认关。人特别多、坐得特别远时能多找出一些，代价是变慢。
- **回避刚抽过的人**：默认 6 个。人不会乱动，所以靠人脸在画面里的位置认人，
  刚抽过的几个先跳过。设成「不回避」就是完全独立随机，容易连着抽到同一个人。
- **混入文字抽选**：可选一个概率，按这个概率改成抽名字，照顾没被拍进画面的人。
- **保存原始照片**：默认关。合影是在场者的影像，不开的时候照片只在内存里待到裁完就丢。

**文字抽选可以用单独一份名单**（当前是第几份，就读 `namelib/list几-文字.txt`），
和主名单完全隔离：想让文字抽选只覆盖某几个人时不必动主名单。

## 藏起来之后怎么找回来

右键菜单里没有「隐藏」这一项，藏起来的入口在别处。藏起来之后：

- 托盘图标右键 → **更多选项 → 显示抽选悬浮球**
- 或者 **应用设置 → 随机抽选 → 显示悬浮窗**

隐藏状态会存盘，重启 ClassIsland 也不会自己冒出来，要用上面两条路叫回来。

> 托盘菜单里可能还有一条「显示 / 隐藏悬浮窗」，那是 **SystemTools** 之类的插件自己的悬浮窗，
> 跟本插件没关系。认准带「抽选」的那条。

## 设置项一览

按设置页里的顺序：

| 设置 | 说明 |
|---|---|
| 显示悬浮窗 | 球是显示还是藏起来 |
| 悬浮球大小 | 小 / 中 / 大 |
| 悬浮球人数显示 | 球上那行小字显示人数，还是显示「放回 / 不放回」 |
| 抽取来源 | 拍照抽人 / 随机抽人 / 随机抽组 |
| 抽取数量 | 1 个 / 2 个 / 3 个 |
| 抽取模式 | 不放回 / 放回 |
| 分组方式 | 字母 / 数字 |
| 小组总数 | 1 ~ 26 |
| 重置本轮 | 不放回清本轮记录；放回清降权记录 |
| 屏幕中央弹出 | 抽中后是否在屏幕中央亮出结果 |
| ClassIsland 提醒 | 是否同时发一条主界面提醒 |
| 停留时长 | 1.5 / 2.5 / 4 秒 |
| 选择名单 | 在 5 份名单之间切换 |
| 名单文件 | 打开当前名单、重新加载 |
| 拍照抽人 | 见上一节 |

球上那行小字：打开人数显示时，抽人写 `4/30 人`、抽组写 `2/6 组`（放回模式只写总数）；
关掉后改显示 `不放回` 或 `放回`。拍照模式两种情况下都写「拍照」。
